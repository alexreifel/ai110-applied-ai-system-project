# Real-track catalog

This directory retains the original `songs.csv` (20 synthetic baseline songs) and adds `catalog.jsonl`, the real-track snapshot used by the new recommender. The checked-in snapshot runs locally without downloads or credentials. `catalog_report.json` records observed coverage, cleaning, selected IDs, feature ranges, provenance, and checksums. `genres.json` preserves the source genre hierarchy.

## Attribution and source

FMA: A Dataset For Music Analysis, Michaël Defferrard, Kirell Benzi, Pierre Vandergheynst, and Xavier Bresson, ISMIR 2017. [Dataset and metadata license](https://github.com/mdeff/fma), [paper](https://arxiv.org/abs/1612.01840).

Imported metadata is CC BY 4.0. The derived metadata retains that attribution and license: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). The snapshot selects and transforms metadata; it contains no audio. Individual audio licenses differ, and metadata permission is not permission to redistribute recordings.

Source release: metadata rc1, 2017. [Metadata archive](https://os.unil.cloud.switch.ch/fma/fma_metadata.zip), approximately 342 MiB. The project verifies its published SHA-1 `f0df49ffe5f2a6008d7dc83c6915b31835dfe733` and records the downloaded archive's SHA-256. Only `tracks.csv`, `raw_tracks.csv`, `genres.csv`, and `echonest.csv` are read. No pickles are loaded or archives extracted.

## What was observed

- 106,574 source metadata records; 13,129 have the source feature records used here.
- 13,128 usable candidates; track 26620 was excluded for a blank title.
- 1,200 selected tracks, 775 distinct artist IDs, 113 represented genre labels.
- 16 broad genres represented; 15 have at least 20 tracks. Spoken is sparse at 7 tracks. Genre counts overlap because tracks can have multiple labels/ancestors.
- All 1,200 selected tracks have six numeric estimates: energy, tempo, valence, acousticness, danceability, instrumentalness. No values were imputed.
- 395 selected tracks have energy <= 0.35 and acousticness >= 0.7; 43 have energy >= 0.7 and danceability >= 0.7; 188 have tempo <= 85 BPM and 303 have tempo >= 140 BPM.

These counts describe the actual committed snapshot, not the entire FMA collection or real-world listening preferences.

## Rebuild exactly

From the repository root, with the documented environment active:

```bash
curl --fail --location --output /tmp/ai110-fma-metadata.zip \
  https://os.unil.cloud.switch.ch/fma/fma_metadata.zip
python -m scripts.prepare_catalog /tmp/ai110-fma-metadata.zip --output /tmp/ai110-rebuilt-data
diff data/catalog.jsonl /tmp/ai110-rebuilt-data/catalog.jsonl
diff data/catalog_report.json /tmp/ai110-rebuilt-data/catalog_report.json
diff data/genres.json /tmp/ai110-rebuilt-data/genres.json
```

This is a preparation step, not part of running the application. The ZIP can stay outside the repository. The builder uses Python's standard library. Its default sample size is 1,200. It follows the source genre hierarchy, orders tracks with a deterministic SHA-256 key, selects round-robin across broad genres with at most three tracks per artist, and writes records in ascending ID order. Those choices favor coverage and change the original distribution; this is not a representative random sample.

Transformations: decode HTML entities/collapse whitespace in titles and artist names; strip/casefold genre labels; derive ancestors from explicit parent edges; convert source numeric strings to validated numbers; rename tempo to `tempo_bpm`; upgrade source FMA URLs from HTTP to HTTPS. No song identity, numeric feature, genre, or URL slug is generated by AI. Exact changes and record selections are described in the report.

## Meanings and limits

The features are historical algorithmic estimates in [0,1], except tempo in positive BPM. Energy is not the same as tempo. Valence is an estimate of musical positiveness, not a verified mood or a promise about a listener's feelings. Acousticness and instrumentalness are estimates, not instrumentation labels or guarantees of absent vocals. The app has no verified lyrics, explicit-content safety, recent popularity, or availability fields.

Direct genre labels come from source metadata. `genres` also includes their explicit ancestors for matching: for example, a track labeled psych-folk can match a folk request. Overlapping genre labels make broad exclusions conservative: excluding electronic removes any track with electronic among its source-derived ancestors.

This snapshot is historical and weighted toward independent music. Some genres/subgenres remain rare or absent. Old references may no longer offer playback. A reference identifies the source record; it is not a guarantee that a link currently resolves. Recommendations indicate metadata similarity, not verified enjoyment, objective quality, or confidence.
